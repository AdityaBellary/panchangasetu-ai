# PanchangaSetu

Ask the TTD panchangam a question in Telugu or English and get an answer taken from the book, with the page it
came from. Asking needs an API key from the owner.

Source code and setup: https://github.com/AdityaBellary/panchangasetu-ai. This Space is deployed automatically
from `main` by the repository's `deploy` workflow; don't edit it here.
